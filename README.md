# Sales summary in R

**AI assistance:** ChatGPT through Codex helped draft this documentation and the example. See `Appendix.md` for the actual requests and verification status.

This small R project demonstrates how to summarize a synthetic sales table. The example calculates total sales for three products and identifies the product with the highest total.

## Files

- `sales_summary.R` builds the synthetic data and calculates the totals.
- `Script_Documentation.Rmd` describes the script, its inputs and outputs.
- `Reflection.md` contains a draft reflection to review.
- `Appendix.md` records AI use and verification.

## Requirements and setup

Install R. The script uses base R and does not need additional packages. To knit the R Markdown file, install the `rmarkdown` package and its dependencies.

## Run the example

From this folder, run the script in R or RStudio:

```r
source('sales_summary.R')
```

The result is a product-level summary printed in the R console. All records in the example are synthetic.
