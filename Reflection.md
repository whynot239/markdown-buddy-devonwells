## Documentation choices

A reader needs to understand the project's purpose, setup and expected output before running the script. The README puts those details first, while the R Markdown document explains how the script turns synthetic sales records into product totals. A small example makes the calculation easier to follow.

Running the R script provides a check that the example produces the output described in the documentation. Markdown preview and knitting the R Markdown file are separate checks: they reveal whether headings, lists and code chunks render as intended. Comparing the structure with an established R repository also helps identify sections that a new reader might expect.
